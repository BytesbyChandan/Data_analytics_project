# Data Analytics Project

This project demonstrates an end-to-end **Data Analytics workflow** using Python, SQL, Pandas, and data visualization techniques.

## Project Objectives

- Import and understand raw data
- Clean and preprocess the data
- Perform Exploratory Data Analysis (EDA)
- Analyze customer, product, and order data
- Use SQL and Python to answer business questions
- Identify trends and patterns
- Create meaningful visualizations
- Generate actionable insights from the data

## Tools & Technologies

- **Python**
- **Pandas**
- **NumPy**
- **SQL / MySQL**
- **Matplotlib**
- **Jupyter Notebook**
- **CSV**

## Key Analysis

The project includes analysis such as:

- Which customers spend the most?
- What are the best-selling products?
- What is the highest-selling product in each category?
- Customer purchasing behavior
- Product and category performance
- Order and sales trends

## Skills Demonstrated

**Data Cleaning → Data Transformation → SQL Analysis → Exploratory Data Analysis → Data Visualization → Business Insights**

This project is created to demonstrate practical **data analytics and data-handling skills** and can serve as a portfolio project for Data Analyst and Data Engineering roles.
